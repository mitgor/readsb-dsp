## Integration

Raw completed worker futures enter a causal production-equivalent admission bridge without pre-deduplicating seams. Stream1090 has an independent future, launched from the original full RF window without waiting for the other DSP group. Individual sources enter bounded queues and one shared5-second/120us transmission cache, with a100000-entry cap. Original stock bytes serialize immediately; original candidate sample timestamps are preserved. There is no global sorting delay or wait for an unrelated slow source. Fused C/Rust/frontend computation stays shared and can finish several methods together. Original whole-window grouping is still audited unchanged for statistics and baseline comparison.

The original RF epoch, stock-only prior address, CRC, conflict, clock-alignment (20matches, median≤2µs), enabled-source and RF-age gates remain. Old epochs/futures/anchors are cleared or rejected. Unknown addresses, corrupt CRC, unverified candidates and Broad CRC cannot use the forwarding path. Stock always survives; a later original stock copy after an earlier extra is an explicit race, not silently dropped. Nine integration/control tests pass on both Mac and Pi.

The target worker CPU was14.190s for16RF seconds. Its clock was slowed12x under nice19/core3/35%one-core/1GiB limits to avoid disrupting production. Raw Stream1090 stock/nonstock classification can differ when only causal/cached stock rows are available. The final validated transmission set, rather than raw candidate-list equality, is the retention criterion. Mac uses compatible native Mach-O implementations; Pi uses hash-verified copies of the current production Rust/native libraries and models.

## Preserved engineering failures

A first capture could not create its unowned /run destination. A later capture was rejected by an unnecessarily strict contiguity assertion; its IQ is preserved and reserved, and is not used as the successful reference cohort. The final capture saves explicit RF-copy gaps and complete references. A first observer had a copied module path error; its successful retry has complete read-only source coverage.

The target harness first encountered /run noexec, then disappearing user-owned multiprocessing semaphores. Owned code moved to root-owned executable RAM under established access; no mount, network, permission policy or receiver setting changed. An intermediate quota-limited replay lost five extras when one Stream1090 subprocess hit its unchanged1-second timeout. The coordinator now caches unchanged stock snapshots and polls without unnecessarily spending the quota. The final target run retains all320extras with no timeout. Failed/intermediate artifacts and logs are preserved privately. These are repeated engineering checks on the same RF, not separate prospective confirmations.
